# Dispatcher

運転士の急な欠員で路線バスを減便するときの、減便ダイヤの判断支援ツールです(開発中)。

運行管理者と GTFS 担当者が、次の流れを1つの画面で進めます。

1. GTFS を読み込む
2. 周辺の事業者・学校・病院の状況を調べる(前提情報)
3. 平日ダイヤを土曜・日祝ダイヤに切り替える
4. 時間帯別の到達圏(その場所から、その時間帯に徒歩で乗れるバスがあるか)で影響を地図で確かめる
5. Claude の提案をもとに、通勤・通学・通院に必要な便を足し戻す
6. 期間限定の減便を反映した GTFS-JP を出力し、検証する

アップロードした GTFS はブラウザの中だけで処理し、サーバーには保存しません。

## 手元で動かす

必要なもの:Node.js 22、pnpm 10(`corepack enable && corepack install -g pnpm@10`)、uv

VS Code では、コマンドパレットの「タスク: タスクの実行」から「開発サーバーを起動」を選ぶと、画面とサーバーが同時に起動します(⇧⌘B でも起動できます)。ターミナルで動かす場合は次のとおりです。

```bash
# 画面
cd web
pnpm install
pnpm dev

# サーバー(別のターミナルで)
cd server
uv run dispatcher-server
```

「サンプルを読み込む」ボタンを使うには、北海道オープンデータプラットフォームの利用フォームに記入してから、道北バスの GTFS を `data/raw/gtfs/dohoku_bus_減便前.zip` に置いてください(`data/raw/README.md`)。

## リポジトリの構成

| ディレクトリ | 中身 |
| --- | --- |
| `web/` | 画面(React、TypeScript)。GTFS の処理、到達圏の計算、検証もここで行う |
| `server/` | Claude の中継、利用制限、参照データの配信(Python、FastAPI) |
| `data/` | 参照データ(北海道)の加工スクリプト(Python) |

## データの出典

- GTFS:北海道オープンデータプラットフォーム(道北バスほか、CC BY 4.0)
- 人口:「令和2年国勢調査 地域メッシュ統計」(e-Stat 政府統計の総合窓口)を加工して作成
- 人口集中地区、鉄道、学校、医療機関、バス停留所:「国土数値情報」(国土交通省)を加工して作成
- 背景地図:© OpenStreetMap Contributors(OpenStreetMap Japan のベクトルタイル)
