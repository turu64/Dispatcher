# デモ動画の組み立て(第1版、2026-11-07)

`cuts.json`(カットの表:尺・映像・テロップ・ナレーション)から、`render.py` が動画を組み立てる。

- 必要なもの:ffmpeg(Homebrew)、Google Chrome(字幕・テロップを透明な PNG に描く。フォントは A P-OTF 新ゴ Pr6N)、macOS の `say`(仮のナレーション、Kyoko、速さ 205)
- 置き場所:このフォルダに `img/`(アプリの画面とプリビズの図)、`tts/`(ナレーションの音声)、`ov/`・`seg/`(作業用)を作ってから `python3 render.py`
- 素材の動画は `demo_sozai/`(コミットしない)。出力 `dispatcher_demo_v1.mp4` もコミットしない
- 第1版はアプリの画面を静止画で撮り、ゆっくり寄せている。収録の版では画面の録画に差し替える
