# 元データの置き場所

ここには利用者が手で入手した元データを置きます。中身はコミットしません(`.gitignore` で除外しています)。
スクリプトはデータをダウンロードしません。利用条件に同意してから、ご自身で入手してください。

| 置く場所 | データ | 入手先 | 利用条件 |
| --- | --- | --- | --- |
| `gtfs/` | 道北バスなど北海道の事業者の GTFS(ZIP) | 北海道オープンデータプラットフォーム(ckan.hoda.jp、データセット「gtfs-data」)。**利用前にフォームへの記入が必要** | CC BY 4.0 |
| `mesh/` | 国勢調査メッシュ人口(令和2年、125m・250m、北海道分) | e-Stat 統計地理情報システム | 政府標準利用規約(CC BY 4.0 互換) |
| `did/` | 人口集中地区(A16、2020年) | 国土数値情報 | 利用規約を確認 |
| `rail/` | 鉄道(N02、2024年) | 国土数値情報 | CC BY 4.0 |
| `school/` | 学校(P29、2023年度) | 国土数値情報 | CC BY 4.0 |
| `medical/` | 医療機関(P04、2020年度) | 国土数値情報 | CC BY 4.0 |
| `busstop/` | バス停留所(P11、2022年度) | 国土数値情報 | CC BY 4.0 |
